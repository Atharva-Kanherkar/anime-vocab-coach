04 / WHEN REAL LIFE HAPPENS

The boring parts matter.

Recovery is part of the feature, so a lost connection or changed episode doesn’t become a misleading result.

The connection drops.

A previously authenticated lesson can remain available. A watch receipt is stored locally before delivery, keeps the same event ID on retry, and remains provisional. Hosted practice requires a connection. A known access denial disables cached access until a successful authenticated refresh.

The service worker restarts.

The queue survives in Chrome local storage. Player bindings live in Chrome session storage. A manual refresh or the existing periodic sync retries pending receipts; the API deduplicates repeated delivery. A full browser restart requires confirming the video again.

The episode or account changes.

A changed URL, replaced video or changed player session clears course focus. You confirm the next video explicitly. Account changes invalidate bindings; another account cannot send your pending watch receipts.

Video or audio refuses to stop.

Practice does not open until the selected player acknowledges pause and capture-stop is confirmed. Pending Listening starts are cancelled, including streams acquired after stop. Playback resumes only when you choose to resume it.

Built on the merged foundation.

The server and hosted pilot are already merged. The extension joins them into a usable learner flow.
